# ops — 靶场脚本与部署物料

原型 1/3 的「真实靶场」物料集中地。

## 规划内容

- `chaos-demo/`：故意不稳定的 demo 服务（随机 OOM / 慢 SQL / 磁盘打满 / 连接池打满）
  —— 部署到 160，作为自愈 Agent 的故障源
- `prometheus/`：告警规则与 webhook 配置样例（规则备份自 160 的 analytics-stack）
- `checkers/`：原型 3 检查器的环境上下文采集脚本（如需要跨机执行）

## 纪律

- 靶场只在隔离环境制造故障，**严禁**波及 159/160 上正在运行的业务栈
  （hotel-booking / silver-guardian 是第二三靶场，只读观察，不做注入）
- 脚本一律幂等、可一键清理，落盘前先在本地验证
